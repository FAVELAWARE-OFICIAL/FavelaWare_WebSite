# Imagens

Esta pasta contém todas as imagens do projeto organizadas por categoria.

## Estrutura:
- `backgrounds/` - Imagens de fundo
- `gallery/` - Fotos da galeria
- `logo/` - Logo do FavelaWare
- `partners/` - Logos dos parceiros/idealizadores

## Formato recomendado:
- PNG para logos e imagens com transparência
- JPG para fotos
- WebP para melhor performance (quando possível)
